## 💡 Featured Projects

### 1. 🚗 Driver Drowsiness Detection
**Real-time drowsiness detection system using computer vision**

A Python application that monitors driver alertness by detecting eye closure patterns. The system uses OpenCV's Haar cascade classifiers to detect facial features and alerts the driver through visual warnings and system beeps when drowsiness is detected.

- **Technologies**: Python, OpenCV, Haar Cascades, Computer Vision
- **Features**: 
  - Live webcam monitoring
  - Face and eye detection
  - Drowsiness alerts with Windows beep notifications
  - Configurable sensitivity settings
- **Repository**: [Driver-Drowsiness-Detection](https://github.com/chandanlg7975-source/Driver-Drowsiness-Detection)

### 2. 🍽️ Catering Booking App
**Full-stack catering and event food booking platform**

FeastBook is a complete web application for booking catering services for various events. Built with Streamlit and SQLite, it provides an intuitive interface for customers to browse caterers, make bookings, and leave reviews. The platform includes location-based caterer recommendations and an admin dashboard.

- **Technologies**: Python, Streamlit, SQLite, Web UI/UX
- **Features**:
  - Customer booking system for events (weddings, birthdays, corporate events, etc.)
  - Location-based caterer discovery
  - Dynamic pricing calculation
  - Rating and review system
  - Admin dashboard with analytics
  - Booking receipt generation
- **Repository**: [Catering-Booking-App](https://github.com/chandanlg7975-source/Catering-Booking-App)
